# Sistema de Gestión de Empleados

Este sistema permite gestionar los puestos de trabajo de los empleados de una empresa. Incluye funcionalidades de conexión a SQL Server, almacenamiento de información y generación de reportes.

## 🚀 Tecnologías utilizadas

- C# (.NET Framework)
- SQL Server
- Windows Forms (o WPF, si aplica)
- Visual Studio

## 🧱 Estructura del proyecto

- `pjGestionEmpleados/` - Código fuente del proyecto.
- `SOL_GestionEmpleados.sln` - Archivo de solución principal de Visual Studio.

## ⚙️ Requisitos

- Visual Studio 2022 o superior
- SQL Server LocalDB o Express
